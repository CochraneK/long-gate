# Code of Conduct

Long Gate follows a simple standard: be rigorous about ideas and respectful toward people.

We welcome disagreement about threat models, privacy guarantees, architecture, statistics, and implementation choices. Critique should be specific, evidence-oriented, and aimed at improving the project.

Unacceptable behavior includes harassment, discrimination, doxxing, publishing another person's sensitive data, or using project channels to expose confidential datasets.

For security issues, follow [SECURITY.md](SECURITY.md) instead of posting exploit details publicly.
