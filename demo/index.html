Long Gate is a local-first privacy gateway and capability boundary for AI agents. Raw data stays local; only purpose-appropriate, policy-approved artifacts can approach the network boundary.

Capabilities beat prompts.

A networked agent is not asked to ignore the private directory. The private directory is absent from its capability surface.

Local worker

Can read the private source. Hardened deployment disables network access.

Long Gate

Routes purpose, audits synthetic output, guards aggregates, strips identifiers, and records provenance.

Network agent

Cannot mount the raw-data path. It receives a narrow SafeWorkspace only.
