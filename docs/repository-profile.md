## Recommended repository settings

- enable Issues;
- enable Discussions once there is community traffic;
- enable Private vulnerability reporting;
- prefer squash merge for community PRs;
- require passing CI before merge when branch rules are enabled;
- keep Dependabot enabled;
- add a social preview image when a raster export is available.
