# Long Gate · Agent Handoff

This directory is the Git-resident cold-start entry point for another computer, account, coding agent, reviewer, or maintainer.

## Read in this order

1. [AGENT_HANDOFF.md](AGENT_HANDOFF.md) — immediate takeover brief
2. [STATUS.md](STATUS.md) — current state
3. [TODO.md](TODO.md) — actionable queue
4. [DECISIONS.md](DECISIONS.md) — durable product/security decisions
5. [CONTEXT.md](CONTEXT.md) — architecture and terminology
6. [CHATLOG.md](CHATLOG.md) — public-safe distilled conversation history
7. [SESSION_LOG.md](SESSION_LOG.md) — execution and validation checkpoints

Then read:

- [project-status.json](../project-status.json)
- [Security invariants](../docs/security-invariants.md)
- [Threat model](../docs/threat-model.md)
- [Roadmap](../ROADMAP.md)
- [Continuity standard](../LONG_GATE_CONTINUITY_STANDARD.md)

## Rule

The handoff package summarizes the repository. It is not a second source of technical truth.

Code, tests, executable invariants, manifests, and canonical project status win when anything is stale.
